# Database Implementation Plan

This phase focuses on integrating **PostgreSQL** using **Drizzle ORM** to replace our in-memory data store. We will proceed in chapters to ensure stability and type safety.

## Chapter 1: Infrastructure Setup
- **Goal**: Install dependencies and configure the Drizzle ORM client.
- **Tasks**:
    - Install `drizzle-orm`, `pg`.
    - Install dev dependencies `drizzle-kit`, `@types/pg`.
    - Create `drizzle.config.ts`.
    - Initialize the database client in `src/db/index.ts`.
- **Testing**: Verify connection (requires `DATABASE_URL`).

## Chapter 2: Schema Definition
- **Goal**: Define the database schema that matches our domain types.
- **Tasks**:
    - Create `src/db/schema.ts`.
    - Define `users` table with strictly typed columns (UUID, Email, Role, etc.).
    - Generate the first migration file using `drizzle-kit`.
- **Testing**: Verify that types generated by Drizzle match our `User` domain interface.

## Chapter 3: Repository Implementation
- **Goal**: Create a production-ready Drizzle repository.
- **Tasks**:
    - Create `registry/auth/repository/drizzle.ts`.
    - Implement `UserRepository` interface using Drizzle queries.
    - Handle database errors and map them to domain errors.
- **Testing**: Unit tests for the repository (mocking the Drizzle client).

## Chapter 4: Integration & Migration
- **Goal**: Wire up the new repository to the Auth Service.
- **Tasks**:
    - Update `src/lib/auth-singleton.ts` to switch to `DrizzleUserRepository`.
    - Create a script to run migrations (`npm run db:migrate`).
    - Add `DATABASE_URL` to `.env`.
- **Testing**: Manual verification of Register/Login flows using the real database.

## Chapter 5: Verification
- **Goal**: Ensure everything works end-to-end.
- **Tasks**:
    - Run full test suite.
    - Verify data persistence (restart server and check if users remain).
